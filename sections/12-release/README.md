## Current design

This portfolio records the September 6 development checkpoint. Build 9 is the last recorded TestFlight release. Build 10 introduced the household access and native setup work. Build 11 adds the shared video controls and local Mac delivery. Current screenshots mainly show the September 5 interface with demo content, plus a September 6 Mac capture. They are not a screenshot set for every historical build.

## User journey

Implement → review → run contract/unit tests → validate on hardware → archive the final source → upload → confirm Apple processing and tester availability. Publishing this documentation repository does not perform any of those release steps.

## Design decisions

- Mark screenshots as demo, runtime or design artwork.
- Record passed, skipped, failed and interrupted tests separately.
- Keep the private implementation repository and public design portfolio distinct.
