# Publication style

The portfolio uses a restrained editorial system: navy `#102B3D`, teal `#16776E`, mist `#F4F6F8`, white space and Inter typography in Figma. The PDF uses a readable sans-serif with the same color hierarchy. Numbered sections and short captions keep technical content scannable.

This is the **documentation identity**, not a claim that the app has been reskinned. Original screenshots retain the application’s native styling. Figma text, panels and layout remain editable; screenshot fills preserve the real captures. No synthetic screenshot is presented as a shipped interface.


## Build 13 theme supplement

The Brass Labyrinth supplement uses the application’s charcoal, brass, mineral and ivory palette. Its editable Figma specification and dated screenshots supersede the older application appearance. The earlier navy/teal publication boards remain historical editorial assets.
