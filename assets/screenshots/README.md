# Screenshot provenance

These are application captures, not generated mockups. September 5 iPhone/iPad/TV captures use the existing simulator documentation fixtures. The September 6 Mac capture uses the installed build 11 binary in fixture mode, with a temporary documentation-only bundle identity to isolate it from the owner’s normal app. Fixture screenshots demonstrate layout, not live service access. The isolated copy is not a new released application.

Connection screens, household entity dashboards, personal photos and operational hostnames are excluded from this public collection. Source capture hashes and dates are recorded in [manifest.json](manifest.json). Captures are reused unchanged inside Figma presentation frames. Missing screens are described in the section plans rather than represented by invented screenshots.
